## 🗄️ customer_feedbacks 테이블 구조

### 기본 필드
```sql
CREATE TABLE customer_feedbacks (
    -- 기본 정보
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    created_at TIMESTAMP DEFAULT NOW(),
    
    -- 사진 관련 필드
    digital_photo_link TEXT,              -- 디지털 사진 원본 링크
    physical_photo_url TEXT,              -- 실물 사진 URL
    digital_photo_storage_link TEXT,      -- Supabase Storage 백업 URL (qr-customers-photo 버킷)
    
    -- 고객 피드백
    customer_opinion TEXT,                -- 고객 의견 (자유 텍스트)
    rating INTEGER CHECK (rating >= 1 AND rating <= 5),  -- 평점 (1-5점)
    
    -- 방문 정보
    visit_date DATE DEFAULT CURRENT_DATE, -- 방문 날짜
    booth_location TEXT,                  -- 부스 위치 (예: 'Nhat Chieu', 'Chua Boc')
    
    -- 추천 및 피드백
    would_recommend BOOLEAN DEFAULT TRUE, -- 추천 여부
    positive_feedback JSONB,              -- 긍정적 피드백 (aspects: 선택된 항목 배열)
    negative_feedback JSONB,              -- 부정적 피드백 (code: 개선사항 코드, other_text: 기타 텍스트)
    
    -- 프로모션
    promotion_code_used VARCHAR           -- 사용된 프로모션 코드
);
```

### 인덱스
```sql
-- 효율적인 조회를 위한 인덱스
CREATE INDEX idx_feedback_created_at ON customer_feedbacks(created_at DESC);
CREATE INDEX idx_feedback_visit_date ON customer_feedbacks(visit_date DESC);
CREATE INDEX idx_feedback_booth_location ON customer_feedbacks(booth_location);
CREATE INDEX idx_feedback_rating ON customer_feedbacks(rating);
CREATE INDEX idx_feedback_recommend ON customer_feedbacks(would_recommend);
```

## 📊 관련 테이블

### 1. complaint_list (불만사항 목록)
```sql
CREATE TABLE complaint_list (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    complaint_text TEXT NOT NULL,         -- 불만사항 텍스트
    complaint_code TEXT UNIQUE NOT NULL,  -- 불만사항 코드
    is_active BOOLEAN DEFAULT TRUE,       -- 활성 상태
    created_at TIMESTAMP DEFAULT NOW(),
    order SMALLINT                        -- 표시 순서
);
```

### 2. positive_aspects (긍정적 측면)
```sql
CREATE TABLE positive_aspects (
    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
    aspect_text TEXT NOT NULL,            -- 긍정적 측면 텍스트
    aspect_code TEXT UNIQUE NOT NULL,     -- 측면 코드
    is_active BOOLEAN DEFAULT TRUE,       -- 활성 상태
    created_at TIMESTAMP DEFAULT NOW(),
    order SMALLINT                        -- 표시 순서
);
```

### 3. promotion_code (프로모션 코드)
```sql
CREATE TABLE promotion_code (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    promotion_code VARCHAR,               -- 프로모션 코드
    isUsed BOOLEAN DEFAULT FALSE,         -- 사용 여부
    discount_amount INTEGER DEFAULT 10000,-- 할인 금액
    used_at TIMESTAMPTZ                   -- 사용 시간
);
```

## 🔍 주요 쿼리 예시

### 전체 피드백 조회
```sql
SELECT 
    id,
    created_at,
    customer_opinion,
    rating,
    visit_date,
    booth_location,
    would_recommend,
    positive_feedback,
    negative_feedback
FROM customer_feedbacks
ORDER BY created_at DESC;
```

### 부스별 통계
```sql
SELECT 
    booth_location,
    COUNT(*) as total_feedbacks,
    AVG(rating) as avg_rating,
    COUNT(CASE WHEN would_recommend = true THEN 1 END) as recommend_count,
    COUNT(CASE WHEN would_recommend = false THEN 1 END) as not_recommend_count
FROM customer_feedbacks
GROUP BY booth_location
ORDER BY total_feedbacks DESC;
```

### 기간별 피드백 조회
```sql
SELECT * FROM customer_feedbacks
WHERE visit_date BETWEEN '2025-06-01' AND '2025-06-30'
ORDER BY visit_date DESC, created_at DESC;
```

### 평점별 분포
```sql
SELECT 
    rating,
    COUNT(*) as count,
    ROUND(COUNT(*) * 100.0 / (SELECT COUNT(*) FROM customer_feedbacks), 2) as percentage
FROM customer_feedbacks
WHERE rating IS NOT NULL
GROUP BY rating
ORDER BY rating DESC;
```

### 긍정적/부정적 피드백 분석
```sql
-- 긍정적 피드백 빈도
SELECT 
    jsonb_array_elements_text(positive_feedback->'aspects') as positive_aspect,
    COUNT(*) as frequency
FROM customer_feedbacks
WHERE positive_feedback IS NOT NULL 
    AND positive_feedback->'aspects' IS NOT NULL
GROUP BY positive_aspect
ORDER BY frequency DESC;

-- 부정적 피드백 코드별 집계
SELECT 
    negative_feedback->>'code' as complaint_code,
    COUNT(*) as frequency
FROM customer_feedbacks
WHERE negative_feedback IS NOT NULL 
    AND negative_feedback->>'code' IS NOT NULL
GROUP BY complaint_code
ORDER BY frequency DESC;
```

### 프로모션 코드 사용 현황
```sql
SELECT 
    p.promotion_code,
    p.discount_amount,
    p.isUsed,
    p.used_at,
    COUNT(cf.id) as usage_count
FROM promotion_code p
LEFT JOIN customer_feedbacks cf ON cf.promotion_code_used = p.promotion_code
GROUP BY p.id, p.promotion_code, p.discount_amount, p.isUsed, p.used_at
ORDER BY p.created_at DESC;
```

## 🎨 운영진 대시보드 주요 기능

### 1. 실시간 모니터링
- **최근 피드백**: 실시간으로 들어오는 고객 피드백 확인
- **사진 갤러리**: 고객이 업로드한 사진 모아보기
- **평점 추이**: 시간대별/일별 평점 변화 그래프

### 2. 통계 분석
- **부스별 성과**: 각 부스의 평점, 추천율 비교
- **기간별 분석**: 일/주/월 단위 피드백 트렌드
- **감정 분석**: 긍정적/부정적 피드백 비율

### 3. 고객 인사이트
- **주요 불만사항**: 가장 많이 언급된 개선점
- **강점 분석**: 고객이 좋아하는 포인트
- **추천 의향**: 추천/비추천 비율 및 이유

### 4. 프로모션 관리
- **코드 발급 현황**: 전체/사용/미사용 코드 수
- **사용률 분석**: 프로모션 효과 측정
- **할인 금액 통계**: 총 할인 제공액

### 5. 데이터 내보내기
- **Excel 다운로드**: 선택 기간 데이터 내보내기
- **PDF 보고서**: 월간/분기별 보고서 생성
- **이미지 백업**: 고객 사진 일괄 다운로드
